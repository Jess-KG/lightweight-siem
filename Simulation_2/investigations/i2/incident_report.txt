3. SCOPE
Accounts affected: jsmith, admin01
Systems affected: PC001, DC01
Data potentially affected: Employee names, security numbers and addresses.

4. ROOT CAUSE / ATTACK VECTOR
John Smith downloaded a malicious word file through a phishing email.

5. MITRE ATT&CK MAPPING
I.   WINWORD.EXE spawning cmd.exe           T1204.002
II.  Encoded / hidden powershell window     T1564.003
III. Powershell -> External connection      T1105
IV.  Registry Persistance                   T1547.001
V.   Explicit credential use                T1078.002
VI.  New account created                    T1136.002       

6. IMPACT ASSESSMENT
A file containing PII of 50 employees was exfiltrated to an external IP Address.
This file contained full names, security numbers and addresses of all employees in the finance department.

7. RECOMMENDED CONTAINMENT / REMEDIATION ACTIONS
Isolate John Smith's computer.
Disable svc_update.
Change password of Admin01.
Change password of John Smith.
Force logoff any sessions of admin01 and jsmith.
Review what else svc_update did.

8. DETECTION GAPS IDENTIFIED
Persistance rule was not detected as an alert and had to be searched in events.
