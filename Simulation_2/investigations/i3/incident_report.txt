1. SUMMARY
A suspected external attacker conducted repeated failed logon attempts against the 
admin01 account on WIN-DC01 from IP address 203.0.113.44. Shortly afterwards, the 
same IP address successfully authenticated to WIN-DC01 using the svc_backup account.

Further suspicious activity was subsequently detected on the Domain Controller. 
svchost.exe spawned cmd.exe, followed by the execution of an encoded PowerShell command 
using the -enc parameter. Within 15 seconds, PowerShell activity was followed by a 
network connection to 203.0.113.44 on port 8443.

The correlation between the authentication activity, suspicious process execution, 
encoded PowerShell, and outbound network connection to the same external IP indicates 
that WIN-DC01 was likely compromised.

3. SCOPE
Accounts involved: admin01, svc_backup
Systems involved: WIN-DC01
Data potentially affected: Unknown.

4. ROOT CAUSE / ATTACK VECTOR
Credential attack → Successful access → Command execution → Encoded PowerShell → External network communication

5. MITRE ATT&CK MAPPING
I.   Brute Force: Password guessing         T1110.001
II.  Acess to valid account                 T1078
III. cmd used                               T1059.003
IV.  Powershell spawned by cmd              T1059.001
V.   Encoded parameters on powershell       T1027

6. IMPACT ASSESSMENT
The full extent of the compromise is currently unknown. Further investigation 
is required to determine whether credentials, Active Directory information, or 
other sensitive organisational data were accessed or exfiltrated.

7. RECOMMENDED CONTAINMENT / REMEDIATION ACTIONS
Isolate WINDC01 from external communication.
Block the external IP address.
Restrict svc_backup.
Investigate the chain of cmd.exe and powershell.exe -> the commands run.
Force logout any current sessions on WINDC01 and svc_backup.
Change password to svc_backup.
Conduct an assessment to determine what other systems could potentially have been affected.
